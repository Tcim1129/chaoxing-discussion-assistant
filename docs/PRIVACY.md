# 数据与权限

## 哪些数据保存在本机

- 已采集的课程话题、回复、作者标识、班级归属、时间与图片引用。
- 本地统计、模型分析结果、教师备注、课堂历史和评分记录。
- 用户填写的模型接口、模型名称与 API Key。

这些内容使用浏览器扩展的本地存储，未额外实现密钥加密。卸载扩展、清理浏览器资料或切换浏览器配置可能导致本机记录不可用，重要记录应通过 JSON 备份另行保存。

## 哪些操作会联网

1. 采集、更新发言或读取班级信息时，扩展请求用户当前有权限访问的超星页面和接口。
2. 用户启动 AI 分析时，扩展向其配置的服务发送所选发言与必要上下文。请求通常使用发言代号，但原文中自行写入的个人信息仍可能存在。
3. 用户点击“测试连接”时，扩展向所选模型接口发起简短测试请求。
4. 查看图片引用时，浏览器可能访问图片所在的地址。

项目没有设置用于接收课堂记录的作者服务器。配置自定义接口后，数据处理方式也取决于该接口的运营方。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `storage`、`unlimitedStorage` | 保存讨论内容、分析结果、课堂记录和设置 |
| `scripting`、`webNavigation` | 在课程外框与讨论子页面之间定位、连接并协调采集 |
| 超星网站访问权限 | 读取讨论内容、班级信息和回复分页 |
| HTTP／HTTPS 主机访问权限 | 访问用户配置的兼容模型接口，包括自建服务 |

内容脚本的自动匹配范围为超星网站；较宽的模型访问范围用于支持自定义接口。

## 各类导出文件的区别

| 文件 | 是否可能包含身份或密钥信息 |
| --- | --- |
| 模型配置 JSON | 不导出密钥、最近使用记录或地址中的登录凭据；仍保留接口地址与模型名称 |
| 课堂备份 JSON | 可能包含姓名、平台标识、班级、课程链接、原文和分析结果 |
| 纪要／备注 TXT | 可能包含原文引用和教师自行填写的信息 |
| 评分 CSV | 可能包含学生姓名、班级、讨论时间与评价依据，取决于导出选项 |

“匿名显示”影响界面展示，不能保证所有备份和导出文件均已脱敏。公开反馈请重新制作模拟数据，不要直接上传真实课堂备份、请求日志或截图。
