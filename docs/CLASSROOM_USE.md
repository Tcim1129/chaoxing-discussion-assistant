# 课堂使用案例

## 使用情况与证据范围

截至 2026-10-24，维护者报告已有 **1 位教师实际使用**。使用课次、覆盖学生人数和节省时长尚未统计；这里没有独立核验的采用量数据，也不据此宣称广泛使用或教学效果已得到验证。

## 解决的问题

教师向学生发布话题后，需要及时查看最近一段时间内的学生话题与回复，从发言中了解学生如何解释课程内容、哪些概念仍有疑问。大量讨论分散在多个帖子里，逐个翻阅不便于当堂聚焦。

扩展提供按班级、话题和时段采集的入口，将发言与回复整理到分析页，供教师查看原文、参与情况及内容分析；需要时再手动使用 AI 归纳观点、分歧和待解问题。教师可结合原文判断学生的理解与掌握情况，而不是仅依赖发言字数或自动建议分。

## 后续需验证的内容

- 与教师共同核对样本话题和回复，确认采集覆盖范围。
- 记录具体课堂中哪些聚焦观点或问题帮助了后续讲解。
- 经使用者同意后，收集不含学生身份与原文的反馈。
- 将真实使用记录与模拟截图、模型评测分别保存。

本文不包含课程名称、学校、教师或学生身份。真实课堂材料不随项目开源许可一并发布。
